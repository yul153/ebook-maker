## 3. 함께 들어 있는 서버 설정 파일

{FORMAT_NOTE}

폴더 최상위에 설정 파일 두 개가 들어 있습니다. **서버 종류에 맞는 쪽만 읽히고,
나머지 하나는 그냥 무시되므로 둘 다 올려 두시면 됩니다.**

| 파일 | 해당 서버 | 하는 일 |
|---|---|---|
| `.htaccess` | 아파치 · nginx 앞단의 Apache | MIME 등록, gzip 압축, 캐시 헤더 |
| `web.config` | **IIS (윈도우 서버)** | MIME 등록, 기본 문서 지정 |

`.htaccess`는 점(`.`)으로 시작해서 **FTP 프로그램 기본 설정에서는 목록에 아예
보이지 않습니다.**

> **FileZilla:** 메뉴 `서버` → `숨김 파일 강제로 보이기` 체크

두 파일 모두 **서버 전역 설정은 건드리지 않습니다.** 이 폴더 안에서만 적용됩니다.

## 4. FTP 업로드 시 유의사항

| 항목 | 설정 |
|---|---|
| **전송 모드** | **바이너리 고정** — ASCII로 올라가면 이미지가 전부 깨집니다 |
| 동시 전송 수 | 4~8 권장 ({FILES}개 파일이라 기본값 2면 오래 걸립니다) |
| 숨김 파일 | 위 3번 항목 참고 |
| 확장자 필터 | 업로드 필터·화이트리스트가 걸린 서버라면 `.{EXT}`가 허용 목록에 있는지 확인해 주세요 |

**교체·재업로드 시:** `{SLUG}-tmp` 같은 임시 이름으로 올린 뒤 완료 후
`{SLUG}`로 이름을 바꿔 주세요. 업로드 중인 반쪽짜리 화면이 노출되지 않습니다.

## 6. 문제가 생기면

| 증상 | 원인 |
|---|---|
| 계속 "불러오는 중"에서 멈춤 | `manifest.json`이 없거나 접근 불가 |
| **뷰어 틀은 뜨는데 그림만 전부 엑스박스** | 이미지 파일이 안 올라갔거나, 서버가 `.{EXT}`를 모르는 확장자로 보고 404로 막는 경우. 브라우저 F12 → Network 탭에서 `pages/base/1.{EXT}` 요청이 **404**면 이것입니다 |
| 이미지만 안 보이고 404 (IIS) | `web.config` 누락. 또는 IIS 관리자 → **MIME 형식**에 해당 확장자 추가 |
| 이미지만 안 보이고 404 (아파치) | `.htaccess` 누락 |
| Internal Server Error (500) | 서버가 `.htaccess`/`web.config`의 특정 지시어를 불허. 해당 파일을 지우고 접속되는지 확인 후 회신 주세요 |
| 이미지가 깨져서 나옴 | FTP ASCII 모드로 전송됨 → 바이너리로 재업로드 |

해결이 안 되면 증상과 브라우저 콘솔(F12) 오류 메시지를 함께 회신해 주세요.
